## 代码审查与修复

| 问题 | 修复后的行为 | 主要位置 |
|---|---|---|
| 阅读答完最后一题导致队列重排，文章和解析立即消失 | 按文章 ID 保持本篇，本轮队列固定；主动下一篇才切换 | `ReadingMode.jsx`、`lib/reading.js` |
| 阅读首次显示未记住当前位置，选项答案过于集中 | 首篇立即保存，按 ID 恢复；稳定打散选项、正确下标和解析字母同步变换 | 同上 |
| 新词达到掌握、薄弱词评分后移出队列，翻页又加一导致跳词 | 区分当前词是否移出，继续紧邻下一词；末尾与空队列有边界处理 | `App.jsx`、`lib/queue.js` |
| 复习答题或时间变化使词表途中重新排序 | 进入复习时同时固定进度和到期截止时间 | `App.jsx` |
| 全词库待复习数量与实际入口范围不一致 | 概况中的复习入口打开全词库；范围选择明确可见 | `App.jsx`、`StudyHeading.jsx` |
| 空搜索忽略筛选，结果列表和点击索引不一致 | 生词本队列与搜索结果同源；切换筛选重置位置，显示有效序号 | `App.jsx`、`DetailTabs.jsx` |
| 释义只用透明度隐藏，读屏仍能读到答案 | 未揭晓释义使用 `hidden`；复习默认先回想，词源及笔记同样隐藏 | `StudyCard.jsx`、`DetailTabs.jsx` |
| 拼写及听力从发音、拼写或笔记页泄露词形 | 详情面板遵循词形锁定状态，发音设置仍可操作 | `DetailTabs.jsx` |

| `a/an`、`advertise/-ize` 等合法别名被拼成错误答案 | 接受词库声明的完整词形，错误反馈指向最接近的有效拼写 | `lib/spelling.js` |
| 损坏备份先覆盖记录，再因 null 单词、对象笔记/目标数而崩溃 | 覆盖前校验记录和嵌套设置；本地局部损坏逐字段回退，保留正常记录 | `lib/storage.js` |
| 今日目标输入每敲一个数字立即限制，难以编辑 | 允许完整输入，离开输入框或按 Enter 后提交 | `DailyTargetInput.jsx` |
| 旧生成稿覆盖已修订文章、ID 随重生成改变 | 阅读合并保留旧内容和 ID；词汇题复用 targetId 对应 ID；拒绝重复词条 ID | 详见 [内容导入脚本报告](内容导入脚本审查-2026-09-07.md) |

## 界面与学习路径

视觉方向：浅色纸面、深绿单一强调色，以清楚的学习区和安静的辅助信息为主。桌面结构为导航、主学习区、简洁概况；手机结构为进度、范围、当前练习、底部模式导航。

- 侧栏由 300px 收至 232px，降低重复面板占比；词性及字母分段可收起。
- 题目上方集中学习范围，支持难度、每段、词性、字母分段和全词库；手机同样可直接操作。
- 右侧保留下一步练习和真实计数；统计、薄弱词、备份按需展开。
- 今日词汇目标与累计计数统一用“次”；取消把答对数冒充复习完成数、使用虚构分母的进度环。
- 手机底部改为四个常用模式与“更多”，保留测试、拼写、生词本及收藏入口。
- 阅读增加先读主旨、回文定位、核对解析的提示；完成后保留总结、翻译和长句拆解。
- 增加清晰焦点、跳到学习内容链接、答案反馈播报和减少动画偏好支持；不依靠颜色单独表达答题结果。
- 页面注明辨析和阅读为模拟材料；浏览器语音称为语音合成，未继续使用“真人发音”描述。

布局调整集中在 `src/layout.css`，避免一次性重写现有约 3000 行细节样式。旧样式中的历史层叠尚未整体精简，这是维护上的后续改进项。

## 仍需明确的边界

1. **内容尚未逐条人工审定。** J 页仍有 OCR 漏词/串行线索，`moslem` 等长释义仍需逐页检查。此次没有凭不完整 OCR 批量补词、重编号；不能把 5390 条记录宣传为已核验完整考纲。
2. 19 个改正词头的旧音标可能错配，已移除，保留语音朗读；未凭记忆补写。剩余辨析题还可能有多解，词源中文也并非全面校订翻译。
3. 浏览器检查使用 Chromium 模拟各尺寸，未在真实 iPhone Safari、Windows 桌面启动器逐台验收；语音品质取决于系统语音。
4. 项目尚无 ESLint/React Hooks 自动检查和 TypeScript 检查；本次新增行为测试与独立审查，未声称生产构建能替代这些检查。
5. 线上发布与 Windows 重新打包不在此次交付范围。备份保存在本机，不能认为不同设备自动同步。
