# 内容导入与重生成脚本审查

审查日期：2026-09-07。范围为 `tools/merge_passages.py`、`tools/generate_full_cloze.py`、`tools/merge_cloze.py` 及内容回归测试；与学习内容校正任务分工执行。

## 已修复问题

| 级别 | 复现的问题 | 修复后的行为 |
| --- | --- | --- |
| 高 | 阅读导入直接从旧生成分片重建题库，真实重放会撤销 `read-0002` 的正文、翻译、关键词和题目修订，并删除审校标记 | 以现有题库为基线，只追加新来源；现有内容和学习 ID 保留。首次导入旧题库按唯一标题匹配，并记录原始来源 `seq` 对应的 `sourceKey`，随后按来源键识别 |
| 高 | 阅读分片缺失、JSON 解析失败时仍可能覆盖输出，甚至写出空题库 | 全部来源先读取和校验；缺少输入、坏 JSON、无有效题目或非法题目均报错且不改输出。先完整写临时文件，再替换目标文件 |
| 高 | 自动填空题重新编号，词表重排后旧学习记录可能指向其他题目 | 根据 `targetId` 复用已有题目 ID；已审校的自动题完整保留；保存 `nextItemNumber`，新增题不重新使用已退役的编号。填空导入器同步使用这一编号规则 |
| 中 | 阅读必填字段为 JSON `null` 时被转换为文本 `None`，通过非空检查 | 翻译、题干、解析和选项必须是非空字符串；不接受空值、数值、布尔值、数组或对象 |
| 中 | 填空答案有前后空格时，选项已去空格，答案却仍保留空格 | 在比较、去重和写入前统一标准化答案，保证正确选项与答案完全一致 |

另外缩小了导入验证器的异常捕获范围，避免捕获非数据错误；填空输入文件改用 `Path.read_text()` 读取，避免未关闭的文件句柄。

独立终审补充：自动填空生成入口现在拒绝空值、空白或重复的词条 ID，避免不同词条复用同一题目 ID。专项测试从 `main()` 调用，确认这些非法 ID 输入会报错，现有填空输出字节保持不变。

## 使用边界

本次没有运行会写入正式题库的阅读合并或全量填空生成命令。生成器行为测试全部在临时目录运行；真实题库核对只读，未覆盖其他代理完成的学习内容修订。

阅读合并现在是追加操作，已存在文章的编辑修订应直接维护在正式题库中；导入器不会用旧分片覆盖它。首次迁移的旧记录以唯一标题连接来源；多个旧记录使用相同标题时会报错，需要明确来源关系后再导入。结构与导入测试不代表所有英语题目的答案语义已经逐题核实，语义校正范围见同目录的《学习内容审查-2026-09-07.md》。
