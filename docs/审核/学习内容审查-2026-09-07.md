### 练习语义复核的依据

这些是词典与语法依据，不是历年考试题目来源。新题干为本轮重写的学习材料，未复制词典例句。

- `cloze-0007` 原来把 `rose`、`grew` 作为 `increased` 的错误干扰项。Cambridge 的数据表达说明明确将 rise、increase、grow 都列为数值上升的常见动词；原排除理由不成立。修订后使用上升/下降、句法和词性差异区分。[Cambridge：数据变化的表达](https://dictionaryblog.cambridge.org/2020/06/03/dips-slumps-growth-and-peaks-talking-about-data-2/)、[increase](https://dictionary.cambridge.org/dictionary/english/increase)。
- `cloze-0030` 原来否定 `elected to stay`。Cambridge 单独收录 `elect to do something` 表示选择做某事；现在比较 choose 的词形，并保留该拓展用法。[Cambridge：elect to do something](https://dictionary.cambridge.org/dictionary/english/elect-to-do)。
- `cloze-3519` 原来在改进食谱的语境中把 `improve` 排除，而 refine 的一个义项正是通过小改动使之改善。现改为有明确原油加工线索的 `refine crude oil`。[Cambridge：refine](https://dictionary.cambridge.org/us/dictionary/english/refine)。
- `cloze-3514` 不再把 blossom 当作不能用于开花的词。题干以花已经开放这一阶段与花蕾、叶片、果实区别，保留 bloom/blossom 的学习联系。[Cambridge：bloom](https://dictionary.cambridge.org/us/dictionary/english/bloom)、[Cambridge：植物词汇](https://dictionaryblog.cambridge.org/2024/04/03/talking-about-plants/)。
- `cloze-3516` 不再以女性穿着排除 shirt；词典定义及例句均不将其限定为男性专属。[Cambridge：shirt](https://dictionary.cambridge.org/dictionary/english/shirt)。
- `cloze-3517` 不再断言 pamphlet 只适合政治、宗教。它泛指提供信息或观点的小册子。[Cambridge：pamphlet](https://dictionary.cambridge.org/us/dictionary/english/pamphlet)。

## 验证

内容验证从项目根目录运行，不调用网络、不改写运行时数据：

```bash
env -u PYTHONPATH python3 tools/check_learning_content.py
env -u PYTHONPATH python3 -m unittest discover -s tools -p 'test_learning_content.py' -v
```

全量检查结果：5390 个词条、3522 道词汇题、100 篇阅读、400 道阅读题均通过结构检查；3483 个词条具有可追溯例句。检查覆盖 ID 唯一、数量元数据、单空格、选项去重、布尔型答案、题目答案一致性、例句来源及同步、阅读词数、答案下标、长句引用是否实际出现等。

回归测试覆盖真实故障：多个正确标志、答案字段矛盾、字符串 `"false"` 被当真、重复选项、分离词尾、词义模板混入例句、`stared` 错配 `star`、词头全局替换误伤正常单词，以及阅读题缺解释或布尔值答案。生成器的空输入保护、修订保护和稳定 ID 回归由独立代码审查补充，最终测试数量以本轮终验输出为准。

`tools/add_examples.py` 是显式更新命令，会重建并覆盖例句；数据修订后应先运行它，再运行只读检查。它现在优先使用带修订标记的题目，避免把刚修好的内容又替换成未经核验的旧样本。

## 已知限制和后续专项范围

1. **词表完整性仍待专项核对。** PDF 第 183 页明确包含 jewel、job、joke、journal 等词，但旧 OCR 把它们吞进相邻词的释义；`moslem`（vocab-03050）也出现异常长的串行释义。此轮不凭不完整 OCR 自动拆出新词或重排所有 ID；保留原识别串，后续应逐页重建缺失词及分页边界，再按来源核验。5390 只是目前记录数量。
2. **未修订题仍可能多解。** 批量结构校验只能发现形式错误，不能证明近义词题有唯一语义答案；题库仍需分批复核。不能将现有 `curated` 标签解读为全部题目已经由人工审定。
3. **阅读为模拟材料。** 未查到逐篇真实新闻、研究论文或真题出处，因而不为其中科学、医疗、政策叙述补造来源。题目按文中信息作答，材料中的情境不作为事实或专业建议依据。
4. **答案位置分布偏斜。** 阅读源数据 A/B/C/D 分别为 50/288/60/2，72% 集中在 B；词汇题数据均把正确项放在第一项。运行时必须打散选项并同步答案、解析标记。词汇页已有打散逻辑，阅读页由并行 UI/流程修订处理，源数据不为“看起来均匀”而随意重排。
5. **词源中文仍是规则替换辅助。** `etymologyZh` 包含大量英语残留，不属于完整中文翻译；这次只重新关联已纠错词头的本地词源，没有把全部词源描述成全面审定的中文释义。
