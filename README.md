# 申硕英语 · 词汇学习

面向同等学力申硕英语备考的本地学习应用，使用 React + Vite。词库依据考试大纲第六版附录 OCR 整理，当前有 5390 条记录；部分词条已回源纠错，仍存在待逐页核验的遗漏与串行，记录数不代表完整大纲已逐词审定。

在线版本：[打开学习应用](https://juleyang020-creator.github.io/shenshuo-english-vocab/)。仓库推送到 main 后，由 GitHub Pages 工作流更新。

## 学习方式

- **学习新词**：先回想词义再选择答案，答题后查看例句与释义；确认已熟练的词可退出复习。
- **复习巩固**：按间隔重复安排到期与薄弱词，先回想、揭晓，再按记忆程度评分。右侧入口进入全词库复习，也可选择范围。
- **单词测试**：选择中文释义，支持隐藏词形的听力模式。
- **拼写练习**：听发音、看中文拼写；接受词库明确列出的完整别名与英美拼写变体。
- **语境辨析**：3522 道模拟词汇题，练习词义、词形与固定搭配。
- **短文精读**：100 篇模拟阅读、400 道题；答完保留解析，可看全文翻译及长难句拆解。
- **生词本**：回看已学词，搜索全词库，筛选收藏与薄弱词。

手机底部提供常用模式与“更多”，题目上方可以切换难度、分段及全词库。今日目标按词汇练习次数统计，阅读、辨析题数分别记录。发音使用浏览器语音合成，声音取决于设备可用语音。

## 记录与备份

学习记录保存在当前浏览器，不会自动同步到其他设备。在“备份与恢复”中导出 JSON，再到另一台设备导入。清除浏览器数据可能删除学习记录。词库有本地缓存；本地服务版可在电脑上使用，不能把一次在线访问等同于全部材料已经离线缓存。

## 本地运行与验证

```bash
cd vocab-study-app
npm install
npm run dev
npm test
npm run build
```

浏览器打开 `http://127.0.0.1:5173/`。生产构建输出在 `vocab-study-app/dist/`。

内容验证从仓库根目录运行，不会改写正式题库：

```bash
env -u PYTHONPATH python3 tools/check_learning_content.py
env -u PYTHONPATH python3 -m unittest discover -s tools -p 'test_learning_content.py' -v
```

阅读导入会保留已有 ID 和修订内容，输入分片缺失、损坏或为空时停止写入。词汇题重生成按词条 ID 保留已有题目 ID；已审校题保留原文。不要通过删改 ID 来重排题库。

## 内容来源与核验范围

- 词表 OCR 自考试大纲第六版附录一，原 PDF 仅供本地校对，不随仓库发布。
- 难度分层参考高考、CET-4、CET-6 和 COCA 词表，不等同于考试命中率预测。
- 词源来自 etymonline 数据集，中文为辅助解释，尚未完成全面翻译核验。
- 辨析与阅读为模拟学习材料，并非考试真题。结构检查不能证明每道题语义唯一或材料中的情境为事实。
- 本轮修订、页码与词典依据见 [学习内容审查](docs/审核/学习内容审查-2026-09-07.md)，生成器保护见 [内容导入脚本审查](docs/审核/内容导入脚本审查-2026-09-07.md)。

## Windows 本地版

运行 `sh tools/package-windows.sh` 生成压缩包，解压后双击 `启动学习软件.bat`。打包脚本与历史桌面启动器本轮未做跨系统运行验证。
